# Mizan System Walkthrough

## Overview
We have successfully upgraded "Mizan" to Version 3.2 ("Hybrid Brain - Cerebras Edition"). The system now bypasses Groq rate limits by offloading the heavy "Scholar" generation to Cerebras (`llama-3.3-70b`), while using Groq (`llama-3.1-8b-instant`) for fast, mechanical tasks.

## Components Implemented

### 1. Data Ingestion (`ingest.py`)
- **Source**: `The Quran Dataset.csv` and `Tafsir_al-Jalalayn_tafseer.csv`.
- **Logic**: Merged datasets, created unique IDs (`QURAN-{surah}-{ayah}`), and ingested 6236 documents into ChromaDB.
- **Status**: Success.

### 2. Core Logic (`mizan_core.py`) - v3.2 Hybrid Brain
- **Intern Model** (`llama-3.1-8b-instant` via Groq):
    - **Tasks**: `smart_query_expansion`, `grade_documents`, `verify_citations`.
    - **Benefit**: Fast, high rate limit (~14,400 req/day).
- **Scholar Model** (`llama-3.3-70b` via Cerebras):
    - **Tasks**: `generate_answer`.
    - **Benefit**: Deep reasoning, eloquent narrative, 1M token limit (bypassing Groq limits).
- **Logic Flow**:
    1.  **Intern** expands query (e.g., "intrest" -> "interest").
    2.  **Intern** grades retrieved documents.
    3.  **Scholar** (Cerebras) weaves context into an eloquent narrative.
    4.  **Intern** audits citations for accuracy.

### 3. Execution (`run_mizan.py`)
- **Test Query**: "What does Islam say about intrest?" (Typo intentional)
- **Result**:
    - **Optimized Query**: `What does Islam say about interest?` (Handled by Intern)
    - **Citation Status**: `Verified` (Handled by Intern)
    - **Answer**: A flowing narrative citing Quran 2:275, 2:276, 64:17, etc. (Generated by Scholar/Cerebras)

### 4. Frontend (`app.py`)
- **Framework**: Streamlit.
- **Features**:
    - **Glass Box Sidebar**: Visualizes the hybrid workflow.
    - **Real-time Streaming**: Updates UI as Intern and Scholar complete their tasks.
- **Status**: Implemented and verified.
