# Mizan System Walkthrough

## Overview
We have successfully upgraded "Mizan" to Version 4.1 ("The Safety Net"). The system now features a **Corrective RAG (CRAG)** loop that self-corrects verification failures by refining search queries, powered by an **Enriched Database** (Pillar 2) and the "Hybrid Brain" architecture.

## Components Implemented

### 1. Data Ingestion
- **Standard (`ingest.py`)**: Ingests basic Quran + Tafsir into `chroma_db`.
- **Enriched (`ingest_inventory.py`)**:
    - **Sources**: Quran, Tafsir, and **Quran Dictionary**.
    - **Enrichment**: Injects English definitions of Arabic words (e.g., `Keywords: [Riba: Usury/Interest]`).
    - **Output**: `chroma_db_enriched` (6236 documents).
    - **Status**: Active.

### 2. Core Logic (`mizan_core.py`) - v4.1 Safety Net
- **Hybrid Search**: Vector + BM25 using Enriched DB.
- **Query Fusion**: Generates 3 distinct queries.
- **CRAG Loop (Self-Correction)**:
    - **Critic (`verify_citations`)**: Audits citations and faithfulness. Returns feedback if failed.
    - **Strategist (`analyze_failure`)**: Generates a refined query based on feedback.
    - **Loop**: Retries retrieval (max 2 times) before giving up.
- **Hybrid Brain**:
    - **Intern** (Groq): Query Fusion, Grading, Verification, Failure Analysis.
    - **Scholar** (Cerebras): Answer Generation.

### 3. Execution (`run_mizan.py`)
- **Test Query**: "What does Islam say about intrest?" (Typo intentional)
- **Result**:
    - **Generated Queries**: `['What is the Islamic stance on Riba?', 'Is usury considered a sin in Islam?', 'Is interest forbidden in Islamic law?']`
    - **Retrieval**: Enriched documents retrieved.
    - **Answer**: High-quality narrative generated by Cerebras.
    - **Verification**: Verified by Groq Intern.

### 4. Frontend (`app.py`)
- **Framework**: Streamlit.
- **Features**:
    - **Glass Box Sidebar**: Visualizes Multi-Query, Hybrid Retrieval, Verification, and **CRAG Loop Status** (Feedback, Refined Queries).
    - **Real-time Streaming**: Updates UI dynamically.
- **Status**: Implemented and verified.
